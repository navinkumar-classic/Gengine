\doxysubsection{Detailed Description}
Central class that drives the game loop, rendering, and input/event handling. 

The \doxylink{classEngine}{Engine} coordinates core subsystems\+: window creation, input processing, entity updates, and rendering. It serves as the main runtime environment for the game.
