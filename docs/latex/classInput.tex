\doxysubsection{Detailed Description}
Handles user input and maps key events to high-\/level actions. 

The \doxylink{classInput}{Input} class maintains state for keyboard input, such as whether a key is pressed, released, or held. It also allows mapping strings (actions) to specific keys, enabling flexible control schemes.
